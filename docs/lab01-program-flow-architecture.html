04 / GUI ↔ API contract

Each card maps a user action to its final map or panel effect.

Start Search

Run a two-point route or switch to TSP.

  • POST /api/search or /api/tsp
  • Receive animation_log, path, stats, and explanation
  • Right Drawer opens after animation

Compare

Benchmark the same start/end/profile/scenario.

  • 2 · POST /api/metrics
  • MetricsService runs 6 algorithms
  • Bottom Drawer opens; Right Drawer collapses

Scenario change

Change baseline traffic without mutating the source dataset.

  • GET /api/graph?scenario=...
  • Graph layers are re-rendered
  • Previous results and animation are cleared

7 · Explain + review

Inspect every edge in the final path.

  • Select a step by click, keyboard, or arrow keys
  • FROM → TO, distance, time, congestion, risk
  • The active edge uses a cyan highlight

1 · TSP queue

Select waypoints automatically or reorder them manually.

  • Automatic mode locks drag-and-drop
  • Ordered mode allows reordering
  • Start is never duplicated in the queue

Failure path

Keep the UI stable when a request or route fails.

  • HTTP 400 → alert/error message
  • No route → explanation status
  • searchGeneration blocks stale responses

05 / Cost, graph & traffic scenario

This inset explains why the result is not simply the shortest distance route.

Traffic-aware edge cost

cost = α·distance + β·time + γ·congestion_delay + δ·risk_exposure
Distancedistance_km / MAX_DISTANCE_KM
Timebase_time_min / MAX_TIME_MIN
Congestionactual time − base time; multiplier level 1–5
Risknormalized distance × risk_factor / 5
Profilesbalanced · shortest_distance · fastest_route · avoid_congestion

Graph data transformation

clean JS arrays → dataclass validation → scenario variant → NetworkX DiGraph
Nodeid, name, type, latitude, longitude, metadata
Edgesource, target, distance, time, congestion, road_type, risk
Directiononly traverse outgoing neighbors; never infer reverse edges
Scenariorush_hour raises congestion; rainy_day raises congestion and risk
Cachegraph variants are keyed by scenario; the baseline dataset is not mutated
